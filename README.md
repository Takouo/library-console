# 控制台图书管理系统

一个用 Java 写的控制台图书管理系统，用于练习面向对象、集合、异常处理。

## 功能

- 添加图书
- 删除图书
- 修改图书
- 查询全部
- 按 ISBN 查询
- 借书 / 还书

## 技术栈

- Java 21
- Maven
- 集合（List / Map）
- 自定义异常
- 分层结构（entity / service / exception）

## 如何运行

在 IDEA 中运行 `Main.java`。
